# 🛠️ Infinic - Assistência Técnica

O **Infinic** é um sistema moderno de gerenciamento para assistências técnicas, desenvolvido com as tecnologias mais recentes do mercado para garantir rapidez, segurança e uma ótima experiência para o usuário.

## 🚀 Tecnologias Utilizadas

- **Next.js** (Framework React para web)
- **TypeScript** (Tipagem para evitar erros no código)
- **Vercel** (Hospedagem e publicação do projeto)

## 💻 Como Rodar o Projeto no seu Computador

Siga as instruções abaixo para testar o sistema localmente:

1. **Instale as dependências** do projeto (faça isso apenas na primeira vez):
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

3. **Acesse no seu navegador**:
   Abra o endereço [http://localhost:3000](http://localhost:3000) para ver o sistema funcionando.
